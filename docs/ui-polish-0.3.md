# Πρόγραμμα και controls — έκδοση 0.3.1

Τα αρχικά Task 0.3.1 / 0.3.2 παραδίδονται μαζί στην έκδοση 0.3.1.

Η οπτική γλώσσα παραμένει χαρτί, μελάνι, χρυσές λεπτομέρειες, κορδέλα και σφραγίδες. Τα χρώματα δεν άλλαξαν.

Η Source Sans 3 Variable χρησιμοποιείται στο λειτουργικό κείμενο και στα controls, με πιο ήρεμο βάρος και μικρότερο letter spacing στα κουμπιά. Οι slab τίτλοι και οι χειρόγραφες σημειώσεις παραμένουν. Ελληνικό και λατινικό subset φιλοξενούνται τοπικά και μπαίνουν στο offline cache. Η άδεια OFL βρίσκεται στο `assets/fonts/source-sans-3-LICENSE.txt`.

## Πρόγραμμα

- Αριθμημένα ευρετήρια «01 Οι ασκήσεις μου» και «02 Τα προγράμματά μου». Δημιουργία και επεξεργασία ασκήσεων δίπλα στα προγράμματα στο desktop, διαδοχικά στο κινητό.
- Η επιλεγμένη κάρτα του carousel και το ενεργό πρόγραμμα διακρίνονται: το ενεργό δηλώνεται με «Σε ισχύ» και αστέρι.
- «Προβολή πλάνου» και «Προσθήκη προπόνησης» έχουν ορατές ετικέτες. Η προσθήκη αποτελεί το κύριο κουμπί της κάρτας. Αστέρι, αντιγραφή, μετονομασία και διαγραφή βρίσκονται στη δεύτερη γραμμή, με προσβάσιμα ονόματα και tooltips.
- Τα disclosures, ο editor ημέρας και η επιλογή από τη βιβλιοθήκη κρατούν την ήδη υλοποιημένη λειτουργία, τα δεδομένα και τα συμβόλαια συγχρονισμού.

## Inventory ενεργειών

| Ρόλος | Ενέργειες | Εμφάνιση |
|---|---|---|
| Primary | Αποθήκευση άσκησης/ημέρας/καταγραφής, δημιουργία προγράμματος, προσθήκη προπόνησης, έναρξη από άδειο ιστορικό | Μελανί γέμισμα· χρυσό πάνω στην ενεργή μελανί κάρτα |
| Secondary | Προβολή πλάνου, επεξεργασία, αντιγραφή, ακύρωση, επιπλέον σετ, επόμενες καταγραφές | Λεπτό περίγραμμα, ήπιο hover |
| Text | Νέα άσκηση/πρόγραμμα ως disclosure, ενέργειες λογαριασμού, τίτλος καταγραφής για άνοιγμα | Χωρίς γεμάτη επιφάνεια· σαφές focus |
| Destructive | Διαγραφή στη λίστα/κάρτα, τελική επιβεβαίωση | Διακριτικό κόκκινο κείμενο στην αρχική ενέργεια, κόκκινο γέμισμα μόνο στην επιβεβαίωση |
| State / navigation | Επιλογή καταγραφής, ενεργό πρόγραμμα, τύπος καταγραφής, βέλη ημέρας/carousel | Checkbox ή pressed/current state· ξεχωριστή σημασία από αποθήκευση |

Κοινό radius 7px, ύψη βασικών controls 44–56px, σύντομες μεταβάσεις συγκεκριμένων ιδιοτήτων, ήπιες σκιές, ορατό keyboard focus και διακριτές disabled/active καταστάσεις. Το reduced-motion συνεχίζει να απενεργοποιεί την κίνηση.

## Ιστορικό

Οι ενέργειες βρίσκονται σε δική τους γραμμή κάτω από το περιεχόμενο. Η επιλογή αποκαλύπτει επεξεργασία, αντιγραφή και διαγραφή χωρίς απόλυτη τοποθέτηση πάνω στον τίτλο. Στο κινητό επιτρέπεται αναδίπλωση μεταφράσεων και μεγάλων ονομάτων. Η κενή κατάσταση οδηγεί απευθείας στην Καταγραφή. Η πλοήγηση ημερομηνιών, οι λεπτομέρειες, η επεξεργασία και η σελιδοποίηση διατηρούν την υπάρχουσα συμπεριφορά.

## Επαλήθευση

- `npm.cmd run check`: release consistency, unit/integration, Chromium + WebKit e2e και performance budget.
- Οπτικός έλεγχος Προγράμματος/Ιστορικού, editor ημέρας, λεπτομερειών και επιβεβαίωσης διαγραφής σε desktop και κινητό, ημέρα/νύχτα.
- Έλεγχος overflow και clipping στα controls Ιστορικού σε 320, 390 και 1440px με EL/EN/FR/DE.
- Τα υπάρχοντα browser tests καλύπτουν keyboard ροή βιβλιοθήκης, accessibility με axe, carousel μετά από resize, offline φόρτωση και εκτύπωση. Πρόκειται για browser ελέγχους, όχι δοκιμή με φυσικό screen reader ή φυσική συσκευή.

Performance: shell 1.326.106 / 1.400.000 bytes, διάμεσο LCP 1.472 / 3.500ms και TBT 10 / 500ms στο emulated mobile profile του project. Ο πλήρης απολογισμός και η ολοκληρωμένη αναβάθμιση παραγωγικής βάσης καταγράφονται στο `DEVELOPMENT.md`.
