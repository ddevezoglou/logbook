# Release 0.3.5

## Αλλαγές

- **Καθοδηγούμενες ξεναγήσεις.** Το κουμπί «i» στις ενότητες Καταγραφή, Πρόγραμμα, Πορεία και Προφίλ ανοίγει βήματα με οπτικά παραδείγματα. Υποστηρίζονται οι τέσσερις γλώσσες της εφαρμογής, πλοήγηση με πληκτρολόγιο, κλείσιμο με Escape, επιστροφή του focus και μειωμένη κίνηση.
- **Μηνύματα επιβεβαίωσης και σφάλματος.** Ανανεωμένη εμφάνιση, μεγαλύτερη διάρκεια για τα σφάλματα και επανεκκίνηση του χρονομέτρου σε κάθε νέο μήνυμα. Οι αναγνώστες οθόνης λαμβάνουν την αντίστοιχη ανακοίνωση κατάστασης ή σφάλματος.
- **Μικρές σχεδιαστικές βελτιώσεις.** Απλοποιήθηκε η ένδειξη ενεργού προγράμματος και η λίστα ασκήσεων στις κάρτες ιστορικού χρησιμοποιεί κόμματα.
- **Διόρθωση προσβασιμότητας.** Οι ενδείξεις πεδίων της ξενάγησης χρησιμοποιούν το χρώμα `--muted`, διορθώνοντας την ανεπαρκή αντίθεση που σταματούσε το GitHub Actions deployment.
- **Μικρότερο πακέτο δημοσίευσης.** Τα ελληνικά και λατινικά αρχεία Alegreya Sans 500 παραμένουν διαθέσιμα για τα παλιά σχέδια, αλλά εξαιρούνται από το production artifact, τις αντίστοιχες δηλώσεις γραμματοσειρών και την offline cache. Εξοικονόμηση 33.561 bytes, με αμετάβλητο όριο 1.400.000 bytes.
- **Έκδοση 0.3.5** σε package metadata, μενού, service-worker cache και ελέγχους συνέπειας.
